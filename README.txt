PERRO FLOW V3 — Catálogo + panel para crear productos

Esta versión está preparada para que TÚ agregues tus propios productos:
- Imagen propia
- SKU
- Nombre
- Precio en soles
- Duración
- Categoría
- Disponibilidad
- Renovable
- Destacado
- Descripción
- Condiciones de uso
- Publicar / ocultar
- Editar y eliminar

Los productos publicados aparecen automáticamente en la sección pública "Productos".

IMPORTANTE:
Esta V3 todavía es una demo estática: los datos se guardan en el navegador (localStorage). Por eso NO debes considerarlo aún un panel privado ni una base de datos real. El siguiente paso es conectar Supabase y añadir autenticación de administrador, catálogo compartido, usuarios, saldo, recargas, pedidos y compras.

Cambia el número de WhatsApp en app.js (const WA) por el tuyo.

Comercializa únicamente productos/servicios que tengas autorización para vender y que cumplan los términos de sus respectivos proveedores.
