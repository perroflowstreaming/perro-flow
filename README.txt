PERRO FLOW - versión gratuita de demostración

1. Abre index.html para probar la página.
2. Edita app.js:
   - STORE.whatsapp: coloca tu WhatsApp.
   - PRODUCTS: cambia productos y precios.
3. En app.js, cambia los textos de titular/celular de la pantalla de recarga.
4. Reemplaza publicidad_spotify.png por tus diseños.

Esta versión es un frontend gratuito y guarda la cuenta/saldo de prueba en el navegador mediante localStorage.
Para que varios clientes tengan cuentas reales desde distintos dispositivos, el sistema necesita un backend/base de datos.
Para acreditar Yape automáticamente de forma real, se necesita una integración de pagos que confirme las operaciones; no se debe confiar solo en el monto escrito por el cliente.
